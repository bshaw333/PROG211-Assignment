## What is this project about
In our university result management is done manually and it takes time. So I created a small system using Python OOP to manage student exam results.

## Files in this project
I divided the work into 4 files:

- student.py - For student information (id, name, program)
- exam_record.py - For exam record (course, score)
- results_manager.py - Uses dictionary to store results
- main.py - To run and test everything

## How it meets assignment requirements

Task 1: Created 2 classes Student and ExamRecord
Task 2: Used dictionary {student_id: [records]} in results_manager.py
Task 3: Used Instance methods, Class methods and Static methods
Task 4: GitHub repo is https://github.com/bshaw333/PROG211-Assignment - Public and I invited lecturer
Task 5: It follows DPG because it is open source, modular and works offline
